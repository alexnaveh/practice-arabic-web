04 — backend API (FastAPI / main.py)
Method Route Auth Description
POST /users/register public Validate email uniqueness, hash password with bcrypt, create user, return JWT immediately.
POST /users/login public Strip+lower email, verify bcrypt hash, return JWT. Exact error messages surfaced to client.
GET /words jwt Fetch all words owned by current user. Filtered by user_id from JWT.
POST /words jwt Create a word (arabic, hebrew, description?). Linked to current user_id.
PUT /words/{word_id} jwt Update word fields. Filter by word_id AND user_id — ownership enforced at query level.
DELETE /words/{word_id} jwt Delete a word. Same ownership guard. Cannot delete another user's word.
GET /groups jwt All groups for current user, each with computed word_count.
POST /groups jwt Create group with name + initial word_ids. Junction rows inserted into sublist_words.
PUT /groups/{id} jwt Rename a group.
DELETE /groups/{id} jwt Delete group and all its junction rows in sublist_words.
GET /groups/{id}/words jwt All words belonging to a specific group.
POST /groups/{id}/words jwt Add words to a group. Skips duplicates (idempotent).
DELETE /groups/{id}/words jwt Remove specific words from a group (not delete the words themselves).

07 — selection mode state machine
// isSelecting: boolean | selectedIds: Set<number>
NORMAL MODE ────────────────────────────────────────────
tap card → expand (show Edit / Delete buttons)
tap same → collapse
navbar dropdown → "Selection" → isSelecting = true
SELECTION MODE ─────────────────────────────────────────
all expanded cards collapse immediately
tap card → toggle selectedIds (no expand)
navbar counter: "X selected" (not word count)
action bar appears: SelectAll / Delete / AddToGroup / NewGroup / Cancel
Delete → ConfirmModal → Promise.all(deleteWord) → filter local state
NewGroup → GroupModal(mode="new") → POST /groups → navigate /groups/:id
AddToGroup → fetch groups → GroupModal(mode="add") → POST /groups/:id/words
Cancel → isSelecting = false, selectedIds.clear()
